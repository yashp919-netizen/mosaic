## Sources

### 1. Unilever–Google Cloud Partnership Announcement

- **Source:** Unilever press release / Google Cloud blog
- **URL:** https://www.unilever.com (press release section, February 2026)
- **Date:** February 17, 2026
- **What it informs:** The primary real-world framing for Mosaic. The partnership publicly disclosed a multi-year program to migrate Unilever's data and AI workloads to Google Cloud. This is the "publicly announced CPG cloud-migration" event referenced in PROJECT_BRIEF.md Section 1 and Section 3.

### 2. CIO Dive — Unilever/Google Cloud Coverage

- **Source:** CIO Dive (trade press)
- **URL:** https://www.ciodive.com
- **Date:** February–March 2026
- **What it informs:** Secondary coverage providing detail on the announced program scope — AI-first platform, digital twin ambitions, supply chain forecasting. Informs the problem statement framing in PROJECT_BRIEF.md Section 1 and README Section 3.

### 3. Publicly Reported Unilever Scale Details

- **Source:** Multiple trade and technology publications, 2025–2026
- **Details cited:** 100+ country operations, SAP ECC legacy estate, stated ambition to run 500+ AI projects simultaneously (240 TB/week data volume figure from Unilever's public AI strategy presentations), Pega MDM system as part of the product master infrastructure.
- **What it informs:** The scale numbers used to motivate the problem statement ("the same shampoo SKU exists in 40 country systems"). No internal Unilever data is used or represented.

### 4. Unilever–NVIDIA Omniverse Digital Twins

- **Source:** NVIDIA GTC / Unilever public announcements, 2025
- **URL:** https://www.nvidia.com/en-us/omniverse/ (partnership page)
- **What it informs:** The "digital twins" reference in PROJECT_BRIEF.md Section 1 — downstream AI capabilities that depend on a trustworthy product master. Reinforces the "why this matters" framing without implying any implementation detail.

### 5. SAP S/4HANA Migration Market Commentary

- **Source:** Gartner, IDC, and SAP partner ecosystem publications, 2025–2026
- **What it informs:** The market context for "SAP ECC to cloud-platform migration" as the primary deployment scenario. Industry analysts estimated that the majority of the SAP installed base (predominantly CPG, retail, and manufacturing) would be mid-migration by 2026, creating widespread demand for the tooling Mosaic demonstrates.

### 6. BGE-m3 Technical Report

- **Source:** BAAI (Beijing Academy of Artificial Intelligence) — "BGE M3-Embedding: Multi-Lingual, Multi-Functionality, Multi-Granularity Text Embeddings Through Self-Knowledge Distillation"
- **URL:** https://arxiv.org/abs/2309.07597
- **Date:** 2023 (model; updated weights 2024–2025)
- **What it informs:** The embedding model selection (ADR-0001 context, PROJECT_BRIEF.md Section 5). The multilingual capability documented in the paper is what enables Atlas to map Portuguese column names (`nome_produto`) and Devanagari-mixed names without language-specific heuristics.

### 7. LangGraph Documentation

- **Source:** LangChain / LangGraph official documentation
- **URL:** https://langchain-ai.github.io/langgraph/
- **What it informs:** The interrupt/resume pattern used in `human_review_node`, the `MemorySaver` checkpointer design, and the `StateGraph` API. ADR-0002 references this directly.

## What This Project Does NOT Use From These Sources

This section is the IP-literacy signal. Read it carefully before drawing conclusions about what Mosaic represents.

- **No Unilever internal data, schemas, or systems.** The three synthetic market CSVs (`market_uk.csv`, `market_in.csv`, `market_br.csv`) are generated by `data/synth/generator.py` using Faker with invented brand names and fictional product concepts. None of the column names, values, category codes, or product hierarchies are derived from any Unilever or SAP system.
- **No proprietary migration tooling.** Mosaic does not replicate, reverse-engineer, or borrow from any commercial MDM tool, SAP data migration accelerator, or consulting firm's proprietary mapping framework.
- **No insider knowledge of any company's program.** All framing is derived from public announcements, press releases, and published trade commentary. No individual with insider knowledge of the Unilever–Google Cloud program was consulted in building this project.
- **No confidential architectural information.** The Mosaic architecture (LangGraph, BGE-m3, FAISS, Pydantic, Ollama) is based entirely on open-source tools and publicly available techniques. The design choices are documented in the ADRs in this repo.
- **No claim of endorsement.** Mosaic is not affiliated with, endorsed by, or representative of Unilever, Google Cloud, SAP, NVIDIA, or any other company referenced in the public sources above.

The synthetic data, agent designs, evaluation harness, and benchmark numbers are entirely original to this project.
